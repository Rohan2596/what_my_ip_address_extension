Privacy Policy

Effective Date: November 2026

The What Is My IP Address On Chrome extension helps you quickly view your public IP address, as well as basic location, ISP, and timezone information.

1. Information Collection

This extension does not collect, store, share, or sell any personally identifiable information (PII) or browsing data.

2. Data Sources

The extension fetches your IP information directly from the following third-party APIs:

  • ipify.org (api.ipify.org, api6.ipify.org and api64.ipify.org) – your public IPv4 and IPv6 addresses
  • ipapi.co
  • ipinfo.io

These services determine your public IP and associated metadata (e.g., country, city, ISP) using standard IP lookup methods. Data is displayed locally in the popup and never transmitted to the extension developer.

3. Permissions

The extension uses the following Chrome permissions, as declared in the manifest:

  • storage – used only to cache the last IP lookup result locally for faster loading, to keep a simple on-device counter of lookups so the extension knows when to offer a one-time rating reminder, and (in the popup's own local storage) to remember your light/dark theme choice. Neither is sent anywhere.
  • host_permissions – limited to https://ipapi.co/json/ and https://ipinfo.io/json. The ipify requests (api.ipify.org, api6.ipify.org, api64.ipify.org) are plain cross-origin requests and need no additional permission.

4. Data Storage & Retention

All data is processed and displayed locally. Cached data is stored in Chrome’s local storage and can be cleared at any time by disabling or removing the extension.

5. Third-Party Links

Clicking on any external link (such as API provider websites) will open that page in a new tab under their own privacy policies. This includes the link to the developer's website, smallprep.com, shown in the popup; it is only opened if you click it, and no IP or lookup data is sent with it.

6. Policy Updates

This policy may be updated periodically. Any significant changes will be reflected on this page with a new effective date.
